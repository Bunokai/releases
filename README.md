# Bunokai for Android

Made for the stories that bring us together. Discover anime, keep track of what you watch, and find people who love the same stories.

[Get it on Google Play](https://play.google.com/store/apps/details?id=com.typobunch.bunokai) · [Download the latest APK](https://github.com/Bunokai/releases/releases/latest) · [Bunokai website](https://bunokai.typobunch.com/)

## Install the APK

1. Open the latest release and download the `.apk` file under **Assets**.
2. Open the downloaded file on an Android 7.0 or newer device. If Android prompts you, allow your browser or file manager to install apps from that source.
3. Follow the installation prompts. You can turn that permission off again afterward.

Each release includes the version, Android version code, and SHA-256 checksum so you can verify the file you downloaded.

## Updates

If you installed Bunokai through Google Play, update it through Google Play. If you installed it from GitHub, check this repository for new APK releases.
